# 编程基础 / 开发资源

## build-your-own-x — https://github.com/codecrafters-io/build-your-own-x
"从零造 X"（数据库、编辑器、编译器、游戏引擎、Git…）教程汇总，多语言。
**何时用**：通过造轮子深入理解原理。

## you-dont-know-js — https://github.com/getify/You-Dont-Know-JS
深入 JS 机制（作用域、闭包、this、异步、类型）。**何时用**：打牢或补全 JS 底层认知。有免费在线版。

## javascript-algorithms — https://github.com/trekhleb/javascript-algorithms
JS 实现的数据结构与算法 + 解释 + Big-O。**何时用**：面试复习、查算法实现。

## 30-seconds-of-code — https://github.com/Chalarangelo/30-seconds-of-code
按场景分类的短小 JS/TS 代码片段。**何时用**：快速查"这段逻辑怎么写"。

## github/gitignore — https://github.com/github/gitignore
官方 `.gitignore` 模板集合（按语言 / IDE / OS）。
**何时用**：新项目选忽略规则，直接 `curl` 对应模板；GitHub 新建仓库时也可勾选。
