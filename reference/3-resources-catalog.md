# 资源合集 / 目录

## public-apis — https://github.com/public-apis/public-apis
分类整理的免费公开 API（天气、金融、地理、AI…）。
**何时用**：给项目找免费 API，按类别挑选；注意是否要 Key、有无调用限额。

## awesome-selfhosted — https://github.com/awesome-selfhosted/awesome-selfhosted
可自托管的自由软件清单（网盘、笔记、监控、媒体…）。
**何时用**：想用 Docker 自建某类服务时查有哪些选择；可按 License / 语言筛选。

## the-book-of-secret-knowledge — https://github.com/trimstray/the-book-of-secret-knowledge
运维 / SRE / 安全 / 网络工具与速查宝典。**何时用**：排查问题、找工具、查命令时翻。

## awesome-claude-skills — https://github.com/ComposioHQ/awesome-claude-skills
Claude Agent Skills 精选合集。
**何时用**：想给 Claude Code / Copilot 等增加某能力时，来找现成 Skill；也可参考其组织方式写自己的 Skill。
