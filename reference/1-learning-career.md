# 学习成长 / 求职面试（内容型仓库，按指南阅读）

这些仓库是"知识 / 路线图"，无需安装，直接按站内导航学习。

## developer-roadmap — https://github.com/kamranahmedse/developer-roadmap
前端 / 后端 / DevOps / 全栈 / AI 等交互式学习路线图。
**何时用**：入门或转方向，规划"学什么、按什么顺序"。配套 roadmap.sh 阅读体验更好。

## free-programming-books — https://github.com/EbookFoundation/free-programming-books
多语言免费编程书 / 课程清单。**何时用**：找系统教材或免费电子书。

## freeCodeCamp — https://github.com/freeCodeCamp/freeCodeCamp
免费全栈课程平台（本仓库即平台源码）。**何时用**：零基础系统学，边做题边拿证书。

## project-based-learning — https://github.com/practical-tutorials/project-based-learning
按语言分类的"做项目学技术"教程链接合集。**何时用**：想找实战项目练手。

## coding-interview-university — https://github.com/jwasham/coding-interview-university
完整的软件工程师面试备考计划（算法 / OS / 网络 / 系统设计）。**何时用**：系统性备战编码面试。

## tech-interview-handbook — https://github.com/yangshun/tech-interview-handbook
面试速查：简历、行为面试、算法题型模式、Offer 谈判。**何时用**：快速突击或临场复习。

## system-design-primer — https://github.com/donnemartin/system-design-primer
系统设计入门（缓存 / 负载均衡 / 分片 / CAP…）+ 面试例题。**何时用**：学架构设计、备系统设计面试。

## the-art-of-command-line — https://github.com/jlevy/the-art-of-command-line
命令行高效技巧速查（多语言版）。**何时用**：提升日常 shell 效率。
